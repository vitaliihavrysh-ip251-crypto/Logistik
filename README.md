# Logistik
Сайт буде заточений під компанію яка займається логістикою товарів харчування в промислових маштабах по всій Україні.
1.   Добавити на сайт компанії які користуються нашими послугами голістки.
2.   Добавити бази данних працівників які працюють в самій логістиці, тобто приймальників, вантажників, водіїв, втошніків, охорони, адмінві, і тд..
3.   Добавити на сайт вкладку для адмінів, на якій він зможе розглянути аналітику, тобто в нього буде доступ до звітів а також до самої статистики постачання товару.
4.   Добавити сортуванняя.
5.   Добавити можливість переглянути маршрут самих вантажівок - фур які будуть рухатись по логістичним хабам ну і вже безспосередньо в магазини і не тільки.
